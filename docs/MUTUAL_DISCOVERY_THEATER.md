## What “theater” means

**Theater** = human-pivoted LINK / Socratic sessions (Pi ↔ mentor, Forum Romanum modes B/C). It is **not** the Forum-1 timer scout.

## Hard split vs living scout

| | Living Forum-1 scout | Mutual-discovery theater |
|--|----------------------|---------------------------|
| Job | Probe → teach → cycle report | Human pedagogy / Socratic method research |
| Success | Report on disk + teach ≥1; discover-only default | Session learning quality; verified LINKs |
| KPI | Timer armed; publish seam on **cycle reports** | Never redefine publish/timer health |
| INLINE/drain | Lifecycle INLINE=0; implement via separate drain | Older maximal-session narration is superseded by lifecycle |

Do not treat Mode A Socratic dyads or 60‑minute session finals as scout health metrics. See [DISCOVERY_LIFECYCLE.md](./DISCOVERY_LIFECYCLE.md).
