# DKMS

Type: TOOL

## From [[drive-research-enhancing-local-ai-hypervisor-architecture|drive-research-enhancing-local-ai-hypervisor-architecture]] (2026-06-08)
- Stands for Dynamic Kernel Module Support.
- Is a critical step to prevent Proxmox kernel updates from invalidating out-of-tree NVIDIA driver modules.
- Can be implemented by installing the 'dkms' package.

## From [[drive-research-ubuntu-extreme-hardware-tuning-micro02|drive-research-ubuntu-extreme-hardware-tuning-micro02]] (2026-06-09)
- Used to manage the Realtek r8126 driver.
- Allows out-of-tree modules to be compiled and installed.
