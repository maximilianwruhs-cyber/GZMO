# Letta Filesystem

Type: SYSTEM

## From [architectures-for-agentic-memory-virtual-context-micro07](/entities/architectures-for-agentic-memory-virtual-context-micro07.md) (2026-06-09)
- Defaults to standard vector databases for its Archival Memory.
- Relies on agent-driven semantic search.
- Its agentic loop incurs severe TTFT penalties.
- Its architecture inherently binds memory state closer to the individual agent's microservice instance.
- Treats the LLM as a central OS processor actively managing its own virtual memory.
- Optimal for highly dynamic, unstructured, and exploratory workflows.
- Allows agents to edit their own Core Memory blocks autonomously.
- Well-suited for asynchronous background tasks.
- Researchers attached raw conversational history as simple text files to a Letta agent via this.
- Provided the agent with standard operating system tools like grep, search_files, open, and close.
- Enabled the agent to achieve a remarkable score on the LoCoMo benchmark.
