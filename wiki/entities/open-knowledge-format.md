# Open Knowledge Format

Open Knowledge Format (OKF) defines a standard structure for knowledge representation. It is built on top of markdown pages with frontmatter configuration.

## Features

- Markdown-based content structure.
- Frontmatter containing `type` fields mapping to a defined taxonomy.
- CommonMark compliant linking instead of WikiLinks.
- Deterministic page structures (e.g. `index.md`, `log.md`).
