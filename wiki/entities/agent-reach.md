# Agent-Reach

Agent-Reach is a framework for web access, scraping, and browser automation via session hijacking and sandbox environments.

## Features

- Hermetic sandbox environments under `~/.agent-reach/`.
- Fallback routing via command line interfaces (CLIs).
- Ambient Session Hijacking (ASH) for browser credentials/cookies.
