# Global OverlayFS

Type: CONCEPT

## From [[architecting-the-minimalist-linux-desktop-a-compa-part1|architecting-the-minimalist-linux-desktop-a-compa-part1]] (2026-06-08)
- A rudimentary global overlay is an incomplete and dangerous solution for memory vaults.
- Subjects the fragile flash drive to immense write amplification via relentless copy_up operations.
- Persistently stores forensically sensitive temporary files, defeating the purpose of an amnesic OS.
