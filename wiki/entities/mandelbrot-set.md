# Mandelbrot set

Type: CONCEPT

## From [[dynamics-of-the-unpredictable-micro03|dynamics-of-the-unpredictable-micro03]] (2026-06-09)
- Defined as the bounded set of points c from the complex plane for the recurring series z_{n+1} = z_n^2 + c with z_0 = 0.
- Established the profound link between simple chaotic recursion and infinite geometric complexity.
- Illustrates how a finite area can contain boundaries of infinite length.
