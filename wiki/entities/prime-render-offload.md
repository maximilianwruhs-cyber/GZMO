# PRIME render offload

Type: CONCEPT

## From [[drive-research-ubuntu-extreme-hardware-tuning-micro01|drive-research-ubuntu-extreme-hardware-tuning-micro01]] (2026-06-09)
- Pipeline used in multi-GPU desktop environments when display is not connected to the primary rendering engine.
- Forces frame buffer copies across the PCIe bus.
- Can cause instability and latency.
