- Title: Drive Research Architecting a Linux Task Manager_ Design Principl
- Contains research on architecting a Linux Task Manager.
- Discusses design principles, procfs interaction, and process lifecycle management.
- Serves as a critical bridge between kernel-space scheduling and user-space observability.
- Provides a dynamic, real-time interface for observing hardware utilization, analyzing process states, and exercising administrative control over the process lifecycle.
- Operates in user space, polling the virtual /proc filesystem.
- Calculates mathematical delta between two distinct points in time to derive a real-time CPU utilization percentage.
- Segments memory telemetry into three columns for a nuanced view of resource consumption: VIRT, RES, and SHR.
