# SM121

Type: SYSTEM

## From [drive-research-blackwell-sm120-gemm-optimization-guide](/entities/drive-research-blackwell-sm120-gemm-optimization-guide.md) (2026-06-08)
- Consumer-tier architecture.
- Relies on an extended flavor of mma.sync instructions.
- Register allocation is a primary performance bottleneck.

## From [drive-research-optimizing-cuda-performance-with-fp4-fp6-micro01](/entities/drive-research-optimizing-cuda-performance-with-fp4-fp6-micro01.md) (2026-06-09)
- A specialized variant of the NVIDIA Blackwell GPU architecture (e.g., DGX Spark).
- Designed for unified high-bandwidth memory architectures, integrated with an aarch64 host CPU.
- Routes FP4/FP6 instructions through a different hardware mechanism than SM100, necessitating distinct compile-time flag structures.
- Suffers from silent compilation failures when compiling for GDC instructions using generic targets.
