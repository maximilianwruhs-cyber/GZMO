## From [drive-research-setting-up-autonomous-trading-agents-micro01](/entities/drive-research-setting-up-autonomous-trading-agents-micro01.md) (2026-06-09)
- A deeply integrated, trading-oriented API for Interactive Brokers.
- Allows developers to construct applications using languages like Python, Java, C++, and C#.
- Requires a local instance of Trader Workstation (TWS) or IB Gateway.
- Acts as a TCP Socket Protocol interface.
