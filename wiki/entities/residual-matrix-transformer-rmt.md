# Residual Matrix Transformer (RMT)

Type: CONCEPT

## From [ai-research-part7](/entities/ai-research-part7.md) (2026-06-08)
- Replaced the standard residual stream with an outer-product memory matrix to facilitate feature storage.
- An approach that compromises the inherent identity mapping property of the residual connection.
- Incurs significant memory access overhead due to expanded feature widths.
- An architecture where the residual connection paradigm has established itself as a fundamental design element.
- Introduced Attention and Feed-Forward Networks (FFNs) as fundamental building blocks.
- Its progression is accompanied by the establishment of the residual connection paradigm in LLMs.
