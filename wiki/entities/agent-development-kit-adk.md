# Agent Development Kit (ADK)

Type: SYSTEM

## From [[openclaw-part2|openclaw-part2]] (2026-06-08)
- A Google proprietary framework.
- Seamlessly interoperates with Google Cloud Platform for OpenClaw deployments.
- Provides a robust framework for building deeply integrated, backend multi-agent systems.
- Uses the Agent2Agent (A2A) protocol.
- Allows developers to build specialized agents that can be containerized and deployed natively on the Vertex AI Agent Engine.
- Google's kit for building specialized agents.
- OpenClaw can delegate complex backend tasks to agents built with ADK.
