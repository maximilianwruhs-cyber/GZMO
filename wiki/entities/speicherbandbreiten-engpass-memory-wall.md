# Speicherbandbreiten-Engpass (Memory Wall)

Type: CONCEPT

## From [[drive-research-speicherbandbreiten-engpass-memory-wall|drive-research-speicherbandbreiten-engpass-memory-wall]] (2026-06-08)
- Characterizes the widening gap between computational capacity and memory bandwidth.
- The Key-Value (KV) cache frequently becomes the primary bottleneck for long-context inference and high-concurrency serving.
- Inference speed collapses entirely when the FP16 KV cache pushes a GPU into swap territory.
