# coding agents

Type: CONCEPT

## From [[ai-research-part3-micro03|ai-research-part3-micro03]] (2026-06-09)
- extend LLMs with the ability to operate in conventional computing environments
- ChatDev first illustrated this idea in the context of automated bug fixing
- similar frameworks were later explored in SWE Yang et al. (2024), OpenHands (Wang et al., 2024), MetaGPT (Hong et al., 2024), and AgentLess (Xia et al., 2025)
- Self-Taught Optimizer and Gödel Agent first experimented with agents that modify their own scaffolding
- DGM and SICA extend this direction by implementing self-modifying machines as full software engineering projects
- key limitation in the search heuristics of current self-improving coding agents
- human-level coding agent design performance on SWE-bench Lite
