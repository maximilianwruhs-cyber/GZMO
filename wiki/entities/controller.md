# Controller

Type: CONCEPT

## From [cybernetics-and-mythos-the-architecture-of-intell-part1](/entities/cybernetics-and-mythos-the-architecture-of-intell-part1.md) (2026-06-08)
- The central processing unit.
- Receives sensor data, compares the current state of the variable against a pre-established standard, reference value, or set-point, and calculates the variance or error signal.
- Examples include the brain's temperature-regulatory center and the logic board of a digital thermostat.
