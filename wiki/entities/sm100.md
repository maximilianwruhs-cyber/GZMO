# SM100

Type: SYSTEM

## From [[drive-research-blackwell-sm120-gemm-optimization-guide|drive-research-blackwell-sm120-gemm-optimization-guide]] (2026-06-08)
- Datacenter-class compute capability.
- Uses fifth-generation Tensor Cores and PTX tcgen05 instruction set.
- Introduces 256 KB of Tensor Memory (TMEM) per Streaming Multiprocessor (SM).

## From [[drive-research-imagine-creating-sm120-according-to-our-progress|drive-research-imagine-creating-sm120-according-to-our-progress]] (2026-06-08)

- Features dedicated hardware accumulation space and asynchronous instruction processing.
- Possesses 228 KiB of shared memory (SMEM) per streaming multiprocessor (SM).
- Has 256 KiB of dedicated, on-chip Tensor Memory (TMEM) per warp.

## From [[drive-research-optimizing-cuda-performance-with-fp4-fp6-micro01|drive-research-optimizing-cuda-performance-with-fp4-fp6-micro01]] (2026-06-09)

- Less affected by compilation gaps, synchronization hazards, and memory alignment constraints compared to SM120/SM121.
