# Small Language Models (SLMs)

Type: CONCEPT

## From [engineering-ignorance-eliminating-affirmative-bia](/entities/engineering-ignorance-eliminating-affirmative-bia.md) (2026-06-08)
- Range from 1 billion to 8 billion parameters.
- Democratized access to edge-deployed, latency-optimized AI architectures.
- Struggle to admit ignorance, exhibiting an affirmative bias.
- Default to probabilistic pattern-matching and generate hallucinated responses.
- Become a severe liability when deployed in enterprise RAG pipelines, automated knowledge graph population systems, or closed-book verification tasks.
- Default evaluation templates must be customized when evaluating their pipelines.
- Can be used as a judge itself.
- 3B models have a tendency to accept tangential information as Supported.
- Can be tuned using GEPA.
- Possess systemic training biases that heavily prioritize helpful compliance over strict factual abstention.
- Will inevitably hallucinate, hedge, and over-predict the Supported class when faced with missing information.
- Can achieve strict, unyielding accuracy when properly constrained.
