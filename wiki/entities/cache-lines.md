# cache lines

Type: CONCEPT

## From [[drive-research-cache-optimization-with-ai-chaos-theory|drive-research-cache-optimization-with-ai-chaos-theory]] (2026-06-08)
- Fixed blocks in which memory transactions occur between CPU caches.
- Standardly 64 bytes in size on x86-64 and ARM64 architectures.
- Elements within a buffer can straddle physical cache boundaries if the buffer is unaligned.
