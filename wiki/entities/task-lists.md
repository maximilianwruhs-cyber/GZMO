# Task lists

Type: SYSTEM

## From [[drive-research-creating-a-comprehensive-readmemd-micro01|drive-research-creating-a-comprehensive-readmemd-micro01]] (2026-06-09)
- Task lists are created by prefacing list items with [ ] for incomplete tasks or [x] for completed tasks.
- On platforms like GitHub, referencing an open issue within a task list automatically renders the issue title, creating a dynamic, auto-updating roadmap directly within the README.
- If a task description necessitates a leading parenthesis, developers must utilize a backslash to escape the character to prevent parser errors.
