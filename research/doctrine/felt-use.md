# Felt Use

Felt Use is GZMO living-memory quality on this Keep. A honeypot fact earns MemRL utility_score when later work cites it. Glance retrieval does not mint utility_score.

MemRL two-phase retrieval: build a relevance pool, then rank inside that pool by utility_score (apply_utility_boost). Felt Use is that Q, not raw recall_count.

Brain Feed is a later keep-quality gate. The doctrine row for Felt Use must rank on the operator queries Felt Use, MemRL utility, and Felt Use Brain Feed.
