## 2024-05-22 - TUI Keyboard Shortcut Affordances
**Learning:** In a terminal user interface (TUI) without visible menus or buttons, users often don't know what global hotkeys exist. Hiding global actions like the command palette behind a "Ctrl+P" hotkey without showing it on screen means users have to memorize documentation.
**Action:** Always surface critical global shortcuts (like opening command palettes or quitting) directly on the persistent UI components, such as the bottom border of the primary input box.
