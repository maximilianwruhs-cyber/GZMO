## 2024-05-25 - Empty State Guidance in TUI
**Learning:** Terminal User Interfaces lack visual discoverability for features like command palettes or hotkeys unless explicitly stated. Users staring at an empty input box often don't know what global commands are available.
**Action:** Use empty input fields as an opportunity to provide discoverability hints via dimmed placeholder text (e.g. showing "Ctrl+P for Palette" when input is empty).
